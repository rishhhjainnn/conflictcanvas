🎯 Core Innovation

Zero Silent Data Loss during simultaneous edits using Version Matching & Smart Merge algorithms.

The Problem

The "Last-Write-Wins" Dilemma

Why traditional remote project management tools fail during simultaneous editing.

⚠️ Silent Overwrites

User A marks task as "Completed". User B sets it to "In Review" 1 second later. User A's changes disappear silently.

📉 Lost Team Time

No conflict alerts means developers and managers argue over overwritten statuses, deadlines, and specs.

🔌 Disconnected State

Traditional tools require manual page refreshes or full document locking which breaks modern flow.

The Solution

Intelligent Conflict Resolution

ConflictCanvas solves simultaneous edits with a dual-layer resolution engine.

✨ Layer 1: Smart Merge (Auto)

When users modify different fields (e.g., Rishi edits Status, Vansh edits Priority), the engine automatically reconciles and merges both updates into the next version.

baseVersion == serverVersion ? ACCEPT : AUTO_MERGE
🛡️ Layer 2: Visual Conflict UI

When users edit the same field simultaneously, backend throws 409 Conflict and displays side-by-side versions: Keep Mine, Keep Latest, or Smart Merge.

HTTP 409 Conflict: [Keep Mine | Keep Latest | Resolve]

Data Model

Version Tracking Database Schema

How ConflictCanvas tracks entity versions to guarantee integrity.

🔑 Tasks Table

• id: Primary Key
• title, description, status, priority
• version: Monotonically increasing integer
• created_by, updated_by

⚡ Conflicts Table

• task_id, user_id
• base_version vs server_version
• client_changes & server_changes (JSON)
• status: [OPEN, RESOLVED]
